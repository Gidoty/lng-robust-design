# lng-robust-design

Computational engine and study pipeline for the manuscript *The price of robustness in modular LNG refrigeration: risk-averse design
of single mixed refrigerant and nitrogen expander cycles for variable Niger Delta associated gas* (Tunji Fadoyeni, Gideon Owhonda;
target journal: Gas Science and Engineering).

Code: MIT licence (`LICENSE`). Data: CC BY 4.0 (`LICENSE-DATA`). Cite with `CITATION.cff`.

## Research-integrity rules enforced by the code

1. No result is hard-coded or estimated. Every number in an output file is computed by the engine and traced to a file and row in
   `RESULTS_SUMMARY.md` of the results package.
2. A benchmark that does not reproduce within 5 % is reported as FAIL with its deviation. Nothing is tuned to force agreement.
3. A missing benchmark input is `null` in `lng_robust/data/benchmarks.yaml`; the validator reports `BENCHMARK_INPUTS_INCOMPLETE`.
4. Synthetic compositions carry `synthetic=True` and a parent anchor id in every data file and plot.
5. Every rigorous evaluation, feasible or not, is stored with its failure code (Parquet shards).
6. Every value in `lng_robust/data/design_basis.yaml` is marked GIVEN, ASSUMPTION, TODO or DECIDED. D1 to D11 are DECIDED by the authors
   and are not overridable from the study presets.
7. Surrogate values are never reported as results. They choose where the rigorous solver looks next, and appear only in the
   surrogate-reliability table and figures, labelled as such.
8. The `probe` preset is a timing run. Its numbers are not results.

## Study pipeline (GitHub Actions)

`.github/workflows/study.yml` (generated by `tools/make_workflow.py`) is started by hand (`workflow_dispatch`, input `preset`: `probe` or `full`).
Each unit reads the artifacts of its predecessors, writes a checkpoint and Parquet shards, and uploads them. Stages are chained with `needs:`.

| Stage | Unit (per cycle: smr, n2_single, n2_dual) | Time per job |
|---|---|---|
| 1 | `nominal`: NSGA-II on SEC and UA at the nominal composition; knee design; composite curves | minutes |
| 2 | `sample`: feasibility-guided sampling with active learning near the MITA boundary (Phase 5) | about 1 h |
| 3 | `surrogate`: GB, GP and linear regression, feasibility classifiers, grouped leave-one-anchor-out validation, FFR with Wilson 95 % intervals and counts (Phase 6) | minutes |
| 4 | `robust` x 3 variants (CVaR iso-UA, CVaR UA x1.25, worst-case bound), 3 chained jobs of up to 250 min, checkpoint after every generation (Phase 7) | up to 3 x 4.2 h |
| 5 | `across`: nominal and robust designs over S = 50 scenarios, price of robustness with bootstrap CI (Phase 7/8) | 1 to 2 h |
| 6 | `reversal`: ranking-reversal data on 300 compositions, nominal and robust designs (Phase 8) | 1 to 2 h |
| 7 | `sobol` (surrogate Sobol with additive log-ratio composition, rigorous one-at-a-time confirmation), `sobol_pref` | minutes |
| 8 | `sens`: efficiency, cooler temperature, MITA_min, alpha, SEC_pen, kappa, Field D, Field E cases (Phase 9) | about 1 h |
| 9 | `package`: tables T3 to T7, Figure_1 to Figure_9 (600 dpi PNG and vector PDF), `provenance.json`, `RESULTS_SUMMARY.md`; commits to `results/<run_id>` | minutes |

Evaluation shards (`evals-*.parquet`) are workflow artifacts named `shards-<unit>`; the small checkpoint and result files are `unit-<unit>`.
Fetch with `gh run download <run_id> -p 'shards-*'`. `python tools/zenodo_archive.py --run-id <id>` builds a Zenodo-ready archive (does not upload).

Local run of one unit: `python -m lng_robust.study.cli nominal --cycle n2_dual --preset probe --work work`.

## Layout

| Path | Content |
|---|---|
| `lng_robust/props/eos.py` | Peng-Robinson via `thermo`; TP, PH, PS flashes; exact-key flash cache (`LNG_NO_FLASH_CACHE=1` disables it) |
| `lng_robust/units/`, `cycles/` | compressor, expander, valve, end flash, discretised multi-stream exchanger; SMR, single and dual N2 cycles, spec-based pretreatment |
| `lng_robust/data/` | `design_basis.yaml`, `benchmarks.yaml`, `feeds.csv` (Ebrunu and Akpoturi 2025, Tables 4 to 10), `feeds_sensitivity_fieldE.csv`, `kij_table.csv`, `sources/` |
| `lng_robust/doe/` | feed register, Dirichlet scenarios, `envelope.py` (main envelope without Field D, sensitivity envelopes) |
| `lng_robust/opt/` | `nominal.py` (NSGA-II), `inner.py` (second-stage solvers), `scenario_eval.py`, `ga.py` (checkpointable GA), `robust.py` (earlier in-memory version) |
| `lng_robust/surrogate/` | `active.py` (active-learning sampler), `validate.py`, `stats.py` (Wilson FFR), `starts.py` (surrogate-screened starting points) |
| `lng_robust/study/` | `units.py`, `units2.py`, `cli.py`, `package.py`, `config.py` (presets), `store.py` (Parquet sink) |
| `lng_robust/analysis/` | price of robustness, ranking reversal, figures, efficiency evidence (`inner_benchmark.py`, `cvar_convergence.py`, `profile_eval.py`, `golden.py`) |
| `lng_robust/runs/` | validation, discretisation, property checks, efficiency evidence (CSV) |
| `manuscript/` | the manuscript session's drafts and `REQUESTS_TO_ENGINE.md` |
| `STATUS.md`, `HANDOFF_FOR_MANUSCRIPT_CLAUDE.md` | current state, validation verdicts, versions, incomplete items |
